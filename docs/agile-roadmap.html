Hex en una frase

El handler HTTP solo parsea la request y llama un use case en internal/application/; el use case usa un port (interfaz en internal/domain/ports.go); Postgres implementa el port en internal/infrastructure/postgres/; cmd/server/main.go conecta las piezas. SQL no va en handlers. HTTP no va en domain.

Cómo correr local

cp .env.example .env          # opcional; make ya tiene defaults
make db-up                    # Postgres Docker en :5435
make api                      # Go API en :8080  (otra terminal: make web → Next :3000)
curl http://localhost:8080/health
# esperá {"status":"ok"} — si DATABASE_URL falta, el proceso muere

Frontend: cd web && npm install && cd .. && make web → http://localhost:3000. El browser pega a /api/... y Next reescribe a localhost:8080.

Tests rápidos (no corras go test ./... si no hace falta: entra a web/node_modules):

go test ./internal/application/ -count=1
go test ./cmd/server/ -count=1

Palabras que aparecen en todas las cards

  • Trim: una versión de auto (Corolla XEi 2.0 CVT). No es un aviso.
  • Listing: un aviso concreto (precio, km, año) en vehicle_listings.
  • Seed: datos de demostración metidos por migraciones SQL, source='seed'.
  • Deal: “¿está barato este precio?” → GET /api/v1/trims/{id}/deal?year=&price=.
  • Migración: archivo migrations/00N_algo.up.sql. El server las corre al arrancar. migrations/fs.go ya hace //go:embed *.sql: si el archivo termina en .sql, entra solo.
  • Worker: programa CLI cmd/worker que inserta listings. No es HTTP. make ingest.
  • Domain web vs API: en Railway hay dos URLs. La portada es el servicio web/. /health es la API.

  • Si tocaste web/: cd web && npm run lint.

package normalize

import "strings"

func Title(s string) string {
